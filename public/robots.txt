# Snowtrekk MVP Web — crawl policy
# Public content (destinations, activities, services, guides) is open to crawl.
# Gated/internal app routes and the JSON API are not useful to crawlers and are excluded.
#
# Content-Signal (https://contentsignals.org/) declares usage preferences for
# already-crawled content, on every group below: content may be used for
# search indexing (search=yes) and live AI answers/citation (ai-input=yes),
# but not for training AI models (ai-train=no).

User-agent: *
Disallow: /admin
Disallow: /api/
Disallow: /my-profile
Disallow: /my-shop
Disallow: /checkout
Disallow: /explore
Disallow: /shop/*/chat
Disallow: /user/
Disallow: /business/dashboard
Content-Signal: ai-train=no, search=yes, ai-input=yes
Allow: /
